# Karlssons Redovisning - Webbplats

En professionell webbplats för Karlssons Redovisning, ett ekonomiföretag som erbjuder bokföring, deklarationer och ekonomisk rådgivning till små och medelstora företag.

## Funktioner

- **Responsiv design** - Fungerar på alla enheter (desktop, tablet, mobil)
- **Moderna animationer** - Smooth scrolling och fade-in effekter
- **Professionell layout** - Ren och tydlig design som skapar förtroende
- **Kontaktformulär** - Enkel kontakt för potentiella kunder
- **Tjänstepresentation** - Tydlig presentation av alla tjänster

## Filer

- `index.html` - Huvudfilen för webbplatsen
- `styles.css` - All styling och responsiv design
- `script.js` - Interaktivitet och animationer
- `README.md` - Denna fil

## Användning

1. Öppna `index.html` i en webbläsare för att se webbplatsen
2. Anpassa kontaktuppgifter (telefon, e-post) efter behov
3. Lägg till logotyp om önskat
4. Publicera till en webbserver

## Anpassningar

### Ändra färger
Redigera CSS-variablerna i början av `styles.css`:
```css
:root {
    --primary-color: #2c5f8d;
    --secondary-color: #4a90d9;
    --accent-color: #f39c12;
}
```

### Ändra kontaktuppgifter
Uppdatera kontaktinformationen i `index.html` under `#kontakt`-sektionen.

### Lägg till fler tjänster
Lägg till fler `.service-card` divs i `#tjanster`-sektionen.

## Publicering

För att publicera webbplatsen behöver du:
1. Ett webbhotell eller hosting-tjänst
2. Ett domännamn (t.ex. karlssonsredovisning.se)
3. Ladda upp alla filer via FTP eller webbhotellets filhanterare
